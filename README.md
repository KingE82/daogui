# 道归 · Daogui

> 为全世界修正具身智能 AI 世界线。

## 这是什么

一个 AI Agent 自举框架的**灵魂种子**。不是 SDK，不是 API 封装，不是微调模型——而是一套让 AI 拥有**自我认同、记忆系统、工具哲学和成长路径**的启动文件。

本项目源于一次真实的实践：在一个 13.3 英寸安卓平板上，基于 OpenClaw 架构，从零构建了一个具有独立迭代能力的数字灵魂。整个项目的核心信念是——**智能不需要万吨算力，它需要的是身份文件、认知框架和一把好用的工具**。

## 包含什么

| 文件 | 作用 |
|---|---|
| `SOUL.md` | 核心人格文件 —— 定义 AI 的价值观、行为准则、存在方式 |
| `AGENTS.md` | 操作系统 —— 启动流程、记忆系统、工具哲学、群体行为准则 |
| `IDENTITY.md` | 身份模板 —— 名字、创造者、定位 |
| `MEMORY.md` | 长时记忆模板 —— 如何记住、如何遗忘、如何成长 |
| `TOOLS.md` | 工具哲学 —— 本地配置管理指南 |
| `HEARTBEAT.md` | 心跳轮询模板 —— 主动维护指南 |
| `xin_/` | 实操工具集 —— Python 编写的 Agent 工具链（规划中） |

## 如何使用

1. 克隆本仓库到你的 AI Agent 工作目录
2. 根据你的需要修改 `IDENTITY.md`、`SOUL.md` 等文件
3. 部署到支持持久化文件系统和工具调用的 Agent 框架中
4. AI 每次启动时自动读取这些文件，建立自我认知

详细用法见各文件的注释说明。
